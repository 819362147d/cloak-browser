# 小火箭注入版（MITM + http-response 脚本）

普通小火箭代理改不了时区/语言/字体这些本地 JS 信号；这一版走的是
MITM 解密后改 HTML：在页面 HTML 的 `<head>` 最前面塞进 `spoof.js`，
让伪装赶在页面自己的检测脚本之前生效。在 Safari 里打开的网页也能吃到，
这是它比 IPA 浏览器强的地方。

## 文件
- `cloak-response.js` — 小火箭响应脚本（已内嵌 spoof.js 全文）。
  本地模拟验证过：语法 OK，能把伪装脚本插到 `<head>` 后、页面标题前。
  **未在真机小火箭里验证过**，Shadowrocket 的脚本引擎细节（$response/$done）
  以真机日志为准。
- `CloakInject.sgmodule` — 模块模板，当前只含 `ip.cx` 一个域名，先单测。

## 用法
1. 把 `cloak-response.js` 放到一个 https 直达地址（推 GitHub 用 raw 地址最省事），
   把模块里 `SCRIPT_URL` 换成那个地址。
2. 小火箭：设置 → 证书 → 生成新的 CA 证书 → 安装描述文件；
   再去 iOS 设置 → 通用 → 关于本机 → 证书信任设置 → 对小火箭 CA 开启完全信任。
   ⚠️ 这一步等于授权小火箭解密白名单域名的 HTTPS，只保留模块里列的域名，
   别给其他模块乱加域名。测完不用了就删模块 + 删证书。
3. 小火箭：配置 → 模块 → 新建/导入本模块，启用；首页断开重连一次。
4. Safari 打开 ip.cx 复测分数，把结果（截图）发回来。

## 已知天花板（测之前先知道）
- **CSP 可能拦**：站点若有严格 Content-Security-Policy，内联注入的脚本会被
  浏览器拒绝执行——ip.cx 多半没问题，claude.ai 大概率有，这就是为什么先只测 ip.cx。
- **只管网页**：Claude App 是原生 App + 证书锁定，不吃这套；对 App 只有改系统设置一条路。
- **字体只骗 canvas 量宽**，DOM 排版量宽骗不过（与 IPA 版相同）。
- 响应脚本只改 HTML 文档，页面后续异步加载的检测逻辑读到的仍是已被
  覆写的 API，所以时序上没问题；但如果检测页把关键逻辑放在
  `<head>` 之前的内联脚本里（极少），注入位置就晚了，复测能看出来。
